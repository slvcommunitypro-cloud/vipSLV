# PO Desk

Чистая пересборка Mini App. Старые ключи, Render URL и Supabase-проект в код не входят.

## Состав

- `index.html` — разметка
- `style.css` — оформление в духе Pocket Option
- `script.js` — клиент (Telegram ID, сканер, заметки, калькулятор)
- `server.js` — новый бэкенд
- `config.json` — URL и ключи, которые вы подставите сами
- `users.json` — allowlist Telegram ID
- `ru.json` / `en.json` / `translations.js` — тексты
- `candles.json` — заготовка кэша
- `package.json` — зависимости сервера

PDF из старого репозитория сюда не копировались (чужой контент). Положите книги рядом с `index.html` сами, если нужны.

## Запуск

```bash
cp .env.example .env
npm install
npm start
```

Сервер: `http://localhost:8787`

## Что заполнить после клонирования

1. `config.json`
   - `serverUrl` — адрес нового бэкенда
   - `supabaseUrl` / `supabaseAnonKey` — новый проект Supabase
   - `adminTelegramId` — ваш Telegram ID
2. `.env` на сервере (не коммитить)
   - `PORT`
   - `ADMIN_TELEGRAM_ID`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_KEY` (только сервер)
3. SQL в новом Supabase:

```sql
create table if not exists public.app_users (
  telegram_id text primary key,
  role text default 'member',
  created_at timestamptz default now()
);

create table if not exists public.trader_messages (
  id bigint generated by default as identity primary key,
  created_at timestamptz default now(),
  user_id text not null,
  username text,
  message text not null
);
```

Пока `config.json` пустой, приложение читает доступ через ваш `server.js` + `users.json`.

## Сканер

Не Pocket Option OTC-сокет. Крипта — публичный WebSocket Binance. Форекс/акции/золото — публичный график Yahoo. Список пар тот же, что был в старом приложении.
